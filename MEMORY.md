AES stands for Adaptive Execution System, a working framework organized as objective → milestone → project → task, with a per-session check-in and batch built on top of that structure.
The AES executor cannot pipe data into a skill script's stdin; attempts time out (observed after 120 seconds). Workaround: stage the data as a file in the skill folder, e.g. `aes-core/scripts/snapshot_run.json`, and have the script read it from that path.
AES `scripts/evaluate.py` is run with a file argument, not stdin, and its defaults are: stale objective 30 days, stale milestone 14 days, stale project 7 days, stale act-now 7 days, stale parked text 30 days, stale orphan task 14 days, stale inbox 2 days, objective soft cap 5, due-soon window 3 days, inbox archive retention 90 days.
