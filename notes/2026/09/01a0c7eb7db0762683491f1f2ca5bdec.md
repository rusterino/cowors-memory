## Context

Surfaced during the AES session-start digest, which recorded a skill doc update explaining why the first snapshot run failed.

## Content

The AES executor has no way to pipe data into a skill script's stdin; an attempt to do so timed out after 120 seconds. The workaround is to stage the data as a file in the skill folder (e.g. `aes-core/scripts/snapshot_run.json`) and have the script read it from that path.
