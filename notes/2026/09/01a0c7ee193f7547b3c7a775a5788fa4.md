## Context

The AES snapshot evaluation output listed the framework's configured staleness and cap parameters.

## Content

Default parameters used by the AES `scripts/evaluate.py` check: stale objective 30 days, stale milestone 14 days, stale project 7 days, stale act-now 7 days, stale parked text 30 days, stale orphan task 14 days, stale inbox 2 days, objective soft cap 5, due-soon window 3 days, inbox archive retention 90 days. Evaluations are run with a file argument rather than stdin.
